Layout

Cualquier layout se recalcula al elegirlo o al pulsar "Centrar", nunca entre pasos. El layout "preset" usa la posición guardada en la instancia.

Generar instancia

Edición

Matriz de pesos

Cada casilla es el peso del arco de la fila hacia la columna. Una casilla vacía significa que el arco no existe. La diagonal también se edita: un arco de un nodo a sí mismo es válido. Los nombres de los nodos se escriben en la primera columna.
